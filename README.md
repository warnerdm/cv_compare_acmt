# cv_compare_acmt

Uncertainty of species density from acoustic + midwater trawl surveys, and each gear's contribution (Lake Michigan
2011-2024; ship acoustics by default, 2021 saildrones optional). See `CLAUDE.md` and `STATUS.md`. Run `run_all.R` with R 4.4.0. Methods: `docs/METHODS.md`. Python version of the core steps: `python/README.md`.
